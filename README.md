### How to run (two ways):
* Put `OpenGL` folder in same folder as `main.py`. Then run `main.py`.
* Set up a venv, activate it, and use `pip` to install `pyopengl` and 
  `pyopengl-accelerate`. Then run `main.py`. If that sounds complicated just do
  it the other way.
